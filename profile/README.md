## 概要

学部から依頼を受けて各種システムやプログラムを開発する学生団体です。  
実践的な開発経験を通じて、技術力の向上と学部への貢献を目指しています。

> **Note**  
> 学部公認団体の都合上、総合情報学部生および社会安全学部生のみの加入に限定しています。
